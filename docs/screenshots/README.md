# Screenshots

Drop device captures here for the main README gallery.

Suggested filenames:

| File | Content |
|------|---------|
| `map.png` | Live mapping HUD with AR heatmap |
| `heatmap.png` | Heatmap / both view mode |
| `history.png` | Session history list |
| `export.png` | Share sheet / export result |
| `router.png` | Router placement recommendation |
| `settings.png` | Settings screen |

Then update the root `README.md` Screenshots section:
